Carpeta y ffmpeg (PowerShell)

Todos

Abre PowerShell (menú Inicio → escribe “PowerShell” → Enter), pega esto y presiona Enter. Crea la carpeta, instala ffmpeg y la abre:

New-Item -ItemType Directory -Force "$HOME\Videos\psicologia\clips" | Out-Null
winget install --id Gyan.FFmpeg -e --accept-source-agreements --accept-package-agreements
explorer "$HOME\Videos\psicologia\clips"

Cierra PowerShell y ábrelo de nuevo para que reconozca ffmpeg. Verifícalo:

ffmpeg -version
6

Flujo de trabajo (el bucle)

Todos
  1. En Claude: pide el guion y una lista de planos de 8 s (un video de 5 min son unos 38 planos).
  2. Pega cada prompt en Flow y genera. Descarga el clip.
  3. Guarda los clips en Videos\psicologia\clips con nombres ordenados: 01.mp4, 02.mp4, 03.mp4…
  4. Cuando tengas varios, pega el script de abajo en PowerShell.
  5. Pule el resultado (música, subtítulos) en un editor gratis como CapCut o DaVinci Resolve.
Script para unir todos los clips en video_final.mp4
$dir = "$HOME\Videos\psicologia"
$lista = "$dir\lista.txt"
Get-ChildItem "$dir\clips" -Filter *.mp4 | Sort-Object Name | ForEach-Object { "file '" + $_.FullName.Replace('\','/') + "'" } | Set-Content $lista -Encoding ascii
ffmpeg -y -f concat -safe 0 -i $lista -c:v libx264 -crf 18 -preset fast -c:a aac "$dir\video_final.mp4"
explorer $dir

Vuelve a pegarlo cada vez que agregues clips: reescribe video_final.mp4.
